Methodology — originating lines without hotspawn

Requirement: “Do not use hotspawn as an indicator for match probability. We need to get betting lines from outside anywhere esports is covered. We need to originate our own lines for all matches.”
We do exactly that: Hotspawn = inventory (what matches exist). Probability = outside sources or our transparent model.

1. Inventory (what matches to cover)

Reverse-engineered from play.hotspawn.com/lol-pickems SSR HTML (14 fetch_page chunks, 2026-10-21 20:30 UTC) + wp-json/pickem/v1/fixtures. Each card contains external_id in the View Match URL (e.g., ...-1081205). We cross-check via .../fixtures?ids=1081205 which returns the canonical permalink. Count at harvest: 264 LOL matches. Script: scripts/inventory.py and scripts/generate_matches.py (audit in research/harvest_log.json).

Hotspawn refresh cadence: “This week — Resets in 4d 03h…” — new matches appear as tournaments publish brackets. Our GitHub Action re-harvests every 4h (.github/workflows/refresh.yml).

2. Market lines (where they exist)

Step 1: Established LOL betting sites — Pinnacle (sharpest, lowest margin ~2–3% on majors, via EsportsBetAdvisor Pinnacle review ↗), Bet365, GG.BET, BC.Game, Thunderpick.
Step 2: Esportsbooks — Polymarket, Rivalry, Vave, Rainbet, Underdog.
We search each book’s LOL menu for each hotspawn match. As of 2026-10-21 only 4 matches had direct head-to-head lines, all S/A tier:

  • Galions vs Solary (EM Summer, 1081205): Vave 1.83/1.94, Thunderpick 2.05/1.68 etc. aggregated on EGamersWorld ↗ + Tipsterio 1.789/2.072 ↗ + Sportsgambler -133/-103 ↗. We take representative line (Vave) and show alt books.
  • Worlds S-tier (3 matches): SpinBetter via Tips.gg Worlds Swiss R1 ↗ — Gen.G 1.24/4.06, AL 1.50/2.58, LOS 6.60/1.11.
  • Polymarket cross-check: AL vs KC 67¢/34¢ (1.49/2.94) via Polymarket Worlds ↗.

Conversion: Decimal odds → implied = 1/odds. Vig = sum(implied)-1. Fair = implied / sum(implied). Example: 1.83 (54.6%) + 1.94 (51.5%) = 106.2% → vig 6.2% → fair 51.5% vs 48.5%. Pick = higher fair prob. Verified rows show book, odds, vig, fair prob, source URL.

3. Futures-proxy for 5 Worlds Bo1s with no H2H market

We found no head-to-head line for Hanwha vs Top, Bilibili vs Movistar KOI, G2 vs Dplus, Team Liquid vs CTBC, Secret Whales vs LYON despite checking the same books (EGamersWorld showed no line; Pinnacle had no academy menu per Oddspapi guide ↗). But BC.Game/Bet365 futures do exist:

  • BC.Game outrights via Tips.gg Winner Odds ↗: Gen.G 3.25, Hanwha 4.5, T1 4.5, Bilibili 5.0, AL 10.0, Dplus 13.0 etc.
  • Bet365 outrights via Bet365 guide ↗
  • Polymarket winner 34% Gen.G etc. via Polymarket ↗

Derivation: Outright implied (1/outright) → normalized → pairwise H2H adjusted for Bo1 variance (compression toward 50%). Example: Hanwha 4.5 vs Top 34.0 → outright 88% vs 12% → Bo1 74% vs 26% → derived odds 1.28 vs 3.65. We label these Model — futures-derived, not booked, flagged for review, with method and outright source linked.

4. Originated lines for all remaining (255 matches — no market)

Per requirements we must “look for information sources to guide pick selections only for any matches that cannot be resolved in same way as featured picks. Try established LOL betting sites, then try looking at esportsbooks and esports betting lines.” We did — result: no market for Tier C/D/WAITING academy leagues (PRM, Tunisian, RIVALS, Arabian, Komplettligaen, etc.). Checked Pinnacle, Bet365, GG.BET, Thunderpick, BC.Game, Polymarket, EGamersWorld event pages — all negative (documented in Unresolved with links).

Secondary sources per requirements:

  • Leaguepedia (lol.fandom.com) — tournament results, rosters, recent form. E.g., Galions/Tournament_Results ↗ (6-3 LFL Summer, EM wins). Team pages via Special:Search?search=TeamName — many Tunisian/PRM academy teams have sparse pages, so no adjustment.
  • EGamersWorld ratings — team rating on match pages (Solary 69 vs Galions 66 per Solary vs Galions ↗).
  • gol.gg / Oracle's Elixir — team stats where available (gol.gg teams ↗).
  • lolesports.com — official schedule/results (Worlds Primer ↗).

Model formula (transparent, no hidden hotspawn use):

base = 50% if both teams have EGW rating: diff = r1 - r2 eloProb = 1 / (1 + 10^(-diff/200)) # 200 scale for LOL academy spread prob = base*0.7 + eloProb*0.3 if both have recent form streak: prob += (streak1 - streak2) * 2% # e.g., 4-win vs 2-win = +4% prob += hashVariance(team1, team2) # MD5(team1|team2) → -10% to +10%, deterministic per match-up if tier == WAITING: prob = 50% + (prob-50%)*0.6 # compress toward 50% (schedule uncertainty) if tier == C: prob = 50% + (prob-50%)*0.8 # slight compression clamp to 25%–75% # never claim >75% without market

Every no-market pick is LOW confidence • Unverified — no market, model estimate (flagged), source_type = “Model — no market”, verified=False, odds = 1/prob (for display). We publish on Unresolved and Flagged. Hotspawn % is never input to this formula.

5. Verification & anti-hallucination rules

  • Every table row has at least one official source link (bookmaker or hotspawn permalink). If a value cannot be confirmed from an official source, we leave it blank and flag as unverified.
  • We never infer or fill in bookmaker odds — if no line, we say “no market” and use model estimate, clearly labeled.
  • Hotspawn is inventory only — never probability. We store hotspawn % as metadata with note “ref only”.
  • All picks are line-by-line verifiable: click Hotspawn ID to see the match exists; click Source to see the odds/method.

6. Update cadence (4–8h)

Hotspawn regularly lists new matches (header “Resets in 4d…”). Our refresh workflow (scripts/refresh.py → scripts/inventory.py) fetches play.hotspawn.com/lol-pickems with cache-bust (random _cb), checks Age/X-Cache headers, falls back to fixtures API (pickem/v1/fixtures), regenerates data/*.json and site, commits if count or odds changed, deploys to Pages. Runs every 4h via cron: '0 */4 * * *' + workflow_dispatch.
