Limitations, in plain language

  • No market, no probability. A win probability can only be verified against a price someone is willing to lay. For amateur leagues no book posts a price, so there is nothing to verify.
  • Results data does not exist in machine-readable form. Liquipedia has stub pages for several of these leagues but no per-match scores; the Riot esports API does not carry PRM 2nd/3rd Division, Komplettligaen, Tunisian, 4 Nations, RIVALS LEAGUE or the Icelandic league; bo3.gg has no team record for these rosters.
  • Rosters and form are not usable here. The only roster data available for these fixtures is on Hotspawn itself, which is excluded as a probability input by design.
  • This is not a gap we can close with a better model. Adding a model would add assumptions, not data. A 50/50 prior is the only defensible null value, and a 50/50 “pick” is not a pick — so we show nothing and say so.
