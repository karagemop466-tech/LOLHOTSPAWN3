📐 Method & Sources

Probability ladder (applied in order)

  1. Tier A — Multi-book consensus: average/no-vig across ≥3 books (Stake, Betway, GG.Bet, bet365, 1xBet via esports-news.co.uk) cross-checked vs Polymarket.
  2. Tier B — Single-book line: no-vig: p = (1/odds) normalised so both sides sum to 100% (removes bookmaker margin).
  3. Tier C — Own line: no book exists → standings points, recent form, head-to-head, roster pedigree from Liquipedia/Leaguepedia/event coverage. Deliberately kept near 50% unless evidence is one-sided.
  4. Tier D — No verifiable edge: 50/50, flagged red. Never dressed up as analysis.

Hotspawn pick-% is NEVER used as a probability input (per requirements) — it's sentiment, not a line.

Hotspawn reverse-engineering notes

play.hotspawn.com/lobby is a JS app: server HTML only contains the default CS2 tab (138 matches/week, weekly reset, points/tier/multiplier per match, "View Match" → hotspawn.com/matches/<slug-id>). The LoL tab loads client-side, so automated checks use Liquipedia's fixture feed as the universe (Hotspawn mirrors the same pro calendar) and verify featured events against LoLEsports. Each refresh re-checks for newly listed matches and newly published odds.
