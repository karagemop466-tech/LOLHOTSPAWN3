Review items

F1 · Previous session published 8 hand-typed fixtures with third-party odds stringshigh

Commit a730803 (merged to main as PR #1 from branch arena/a8d3a4de-lolhotspawn3) shipped data/matches.json containing 8 hand-written matches with prose odds such as "Stake 1.25/4.0 · Betway 1.22/3.8 · GG.Bet 1.22/4.02 · bet365 1.16/4.5 · Polymarket 78c/23c" attributed to tipster/SEO pages (tipsterio.de, sportsgambler.com, esports-news.co.uk) rather than to bookmaker APIs. Those prices cannot be re-verified from an official source and the same fixture was priced from a different book on each row. Its 'refresh' workflow also re-ran a build script that fetched nothing, so the data would never change.

Evidence: git show a730803:data/matches.json · git show a730803:.github/workflows/refresh.yml

Status: Superseded in this branch: the dataset is now generated by <code>scripts/collect.mjs</code> from the Hotspawn lobby + Pinnacle + Thunderpick, one consistent primary book per fixture, with a source link on every row.

F2 · GitHub Pages deploy workflow failed on every push to mainhigh

The repository's Pages site is configured for legacy branch deployment from main, but PR #1 added .github/workflows/pages.yml using actions/deploy-pages. Every run since has failed at 0s (runs 39669259401, 39669471096, 39670247282, 39670248612), so the uploaded site was never published and the live URL kept serving the old build.

Evidence: gh run list --workflow=.github/workflows/pages.yml → conclusion=failure, duration 0s

Status: Fixed in this branch: Pages source set to branch <code>main</code>, folder <code>/docs</code> (legacy build, no workflow needed). The broken workflow file is removed.

F3 · www.hotspawn.com blocks automated clients (Cloudflare)medium

Match pages and the WordPress JSON API on www.hotspawn.com return HTTP 403 with a 'Just a moment...' challenge to GitHub Actions egress. So per-match pages cannot be re-verified by the scheduled job and the canonical URLs are taken from the lobby's rendered cards instead (195/195 upcoming cards carry one).

Evidence: Collector error log: status 403, body starts ...Just a moment...; probe hotspawnMatchPage: {status: 403, cloudflare: true}

Status: Worked around, not resolvable. Links are still authoritative because they come from Hotspawn's own HTML.

F4 · 186 of 195 upcoming fixtures have no external markethigh

The Hotspawn LoL lobby is dominated by amateur/semi-pro leagues (PRM 2nd & 3rd Division, Tunisian Super League, RIVALS LEAGUE, Komplettligaen, Icelandic, Arabian 2nd Division, CELOL B, 4 Nations). No bookmaker lists them, and no data feed exposes their results. Those rows deliberately carry no probability and are published on the Unresolved page with the sources checked.

Evidence: Unresolved page · Source audit

Status: Documented limitation — cannot be fixed without new market/data coverage.

F5 · Pinnacle lists 10 World Championship matchups, only 8 are Hotspawn fixtureslow

Pinnacle's World Championship league includes futures/specials (e.g. 'Region of Winner' with LCK/LPL/LEC/LCS/CBLOL/LCP as participants) alongside matchups. The collector filters to two-participant matchups with a moneyline, which leaves the 8 Swiss round-1 fixtures that also exist in the Hotspawn lobby.

Evidence: https://guest.api.arcadia.pinnacle.com/0.1/leagues/9587/matchups — items with type: "special" are excluded

Status: Handled by design; no action needed.

F6 · Best-of format is null for every Hotspawn fixturelow

All 264 fixtures return best_of: null and series_format: null in Hotspawn's transfer state, even where the bookmaker lists best-of-5 (e.g. EMEA Masters final). The site therefore does not display a format column rather than inferring it.

Evidence: data/matches.json → inventory; raw ng-state has 264/264 nulls

Status: Left blank on purpose (no inference).

F7 · Team-name variance between sources (LØS vs LOS, Bilibili vs Bilibili Gaming)low

Hotspawn uses 'LØS', Pinnacle 'LOS'; 'Anyone's Legend' appears as 'AG.AL' on some books. Name normalisation folds ø/æ/ł, strips club suffixes and applies a documented alias table; the first collector run failed to map LØS vs T1 because 'ø' was stripped to 'ls'. Fixed and re-verified: the fixture now maps and appears in the market table.

Evidence: Collector run 1 diag: mapping attached 16/18 · run 2: 18/18

Status: Fixed.

F8 · 69 completed/started fixtures have no per-match URLlow

Hotspawn only renders cards — and therefore match links — for upcoming fixtures. The 69 fixtures whose start time has passed are present in the transfer state but have no card, so no canonical URL can be extracted. Their rows link to the lobby instead and are marked unverified.

Evidence: data/matches.json → hotspawnUrlSource: "constructed-slug" rows

Status: Documented on the Picks page; completed fixtures are excluded from picks.

F9 · Leaguepedia and Oddspedia are unusablemedium

Leaguepedia's Cargo API answers {"error":{"code":"ratelimited"}} from both browser-origin and Actions requests, so no community stats could be pulled from it. Oddspedia's LoL esports page returns HTTP 410 Gone. Neither is used anywhere in the dataset.

Evidence: research/sources-summary.json leaguepedia block · Oddspedia 410 capture

Status: Excluded from the pipeline; recorded in the source audit.

F10 · Hotspawn pick'em percentages are stored but excluded from every calculationlow

The lobby exposes a crowd-pick percentage per team. The brief forbids using Hotspawn as a probability indicator, so the collector stores the figure for transparency only (hotspawnPickedA/B in the JSON) and no code path reads it. It is not displayed as a probability anywhere on the site.

Evidence: scripts/collect.mjs — fields captured, never referenced by the model or the site build

Status: By design.

F11 · Parallel session's MODEL_STANDINGS probabilities are not reproduciblehigh

Branch arena/40177473-lolhotspawn3 (merged to main as PR #4) published 171 of 264 fixtures with a probability whose evidence string is of the form "Official Komplettligaen 2026 Autumn Standings: 7-4 (64%) vs unranked". Those standings could not be found in any source reachable by automation: the Liquipedia pages for Komplettligaen 2026 Autumn (7.5 KB) and RIVALS LEAGUE Season 2 (8.5 KB) are infobox-only stubs with no match rows, bo3.gg has no such tournaments and no team records, and the Riot esports API does not carry these leagues. The only site that renders these standings is Hotspawn's own tournament pages — which are Cloudflare-blocked to automation and are excluded as a probability input by the brief. The numbers therefore cannot be verified or reproduced, so they are not published in this dataset.

Evidence: archive/data/picks.json (preserved, not used) · archive/pages/methodology.html · Liquipedia/bo3/Riot probes in research/

Status: Withheld pending verification. Preserved in <code>archive/</code> so nothing is lost; the live site shows these fixtures as unresolved instead.

F12 · Correction: Polymarket per-match LoL markets were initially missedlow

The first audit queried gamma-api.polymarket.com/events?tag_slug=league-of-legends, which returns only tournament futures ('Worlds 2026 Winning Region'), and concluded that Polymarket had no per-match markets. That was wrong: 9 per-match LoL markets exist (8 Worlds + 1 EMEA Masters) and are readable through /public-search and /events?slug=. The collector now pulls Polymarket as a third independent cross-check, and the audit text was corrected.

Evidence: https://gamma-api.polymarket.com/public-search?q=Galions%20Solary → Galions 0.515 / Solary 0.485

Status: Corrected; Polymarket added as a source.
