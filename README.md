# LoL Hotspawn Picks
Mobile-first pick sheet for every League of Legends match in the Hotspawn Pick'ems lobby.
Probabilities come from outside bookmaker/esportsbook lines (no-vig), never Hotspawn pick-%.
Low-tier matches with no market anywhere get a clearly-labelled own line (Tier C) or honest 50/50 (Tier D).
- Live site: GitHub Pages (docs/) — start at the Executive Summary on index.html
- Rebuild: `python3 scripts/build.py` · Data: `data/matches.json` · Auto-refresh: every 6h via Actions
